# Methodology and assumptions

## Synthetic signal generation

The project generates ideal complex symbols. QPSK and 8PSK use constant-radius phase constellations. APSK uses multiple concentric rings with simplified ring populations. This makes the classes reproducible and gives a controlled input for demonstrating a machine-learning pipeline.

These generated points are not a full communications link simulation. There is no bit mapping, pulse shaping, oversampling, channel, receiver synchronization, or standards-specific APSK optimization.

## Feature vector

Each signal is summarized by 24 values:

1. Real-part mean, standard deviation, skewness, and kurtosis.
2. Imaginary-part mean, standard deviation, skewness, and kurtosis.
3. Magnitude mean, standard deviation, skewness, and kurtosis.
4. Mean and standard deviation of cosine and sine of phase.
5. Real and imaginary minima and maxima.
6. Magnitude minimum and maximum.
7. Mean and standard deviation of adjacent-sample magnitude differences.

Undefined or non-finite moment values are converted to zero so downstream estimators receive finite values. This is a compact baseline, not a complete feature set for automatic modulation recognition.

## Training and evaluation

The dataset builder creates an equal number of records per class. Evaluation uses a stratified random holdout split. The reported accuracy and classification report describe performance on data generated by the same synthetic process. A separate model is then fitted on all generated records and saved for inference.

For meaningful scientific evaluation, split by independently generated capture, channel, or scenario rather than randomly splitting near-identical records. Include real or independently simulated channels and compare against established baselines.

## Interpreting probabilities

Random Forest class probabilities are not guaranteed to be calibrated. They should not be interpreted as physical certainty or as a measure of signal quality. Calibration and out-of-distribution evaluation are future work.
